# Portafolio Web

Portafolio personal creado con **Bootstrap 5** para presentar proyectos, habilidades y datos de contacto de forma profesional.

## Estructura

- `index.html`: página principal del portafolio.
- `assets/css/style.css`: estilos personalizados sobre Bootstrap.

## Cómo visualizarlo

Abre `index.html` en tu navegador.
